# EstructuraDat
EJER - ARREGLOS 26/09/2026
Explicación:
El programa lleva el control de ventas de una tienda con tres departamentos(Ropa, Deportes y Juguetería) a lo largo de los 12 meses del año. Para guardar los datos usé una matriz de 12 filas por 3 columnas, donde cada posición representa el monto vendido en un mes y departamento específico.
El programa inicia muestrando un menú con cuatro opciones: insertar una venta, buscar una venta, eliminar una venta y salir. Cuando el usuario elige una de estas opciones (excepto salir), se le pide seleccionar el mes y el departamento de una lista numerada, y dependiendo de la opción, se guarda un valor nuevo, se muestra el valor existente, o se pone en cero.
Después de insertar o eliminar, el programa imprime la tabla completa de ventas para que el usuario vea el estado actual. Todo esto se repite dentro de un ciclo hasta que el usuario elige la opción de salir.
